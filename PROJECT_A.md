# Project A

Project A is the active experimental effort to run selected **Banjo-Kazooie** world/content data inside this **Banjo-Tooie** recompilation and use that work as the foundation for a new optional expansion.

The public Project A documentation lives in [`docs/project-a/`](docs/project-a/):

- [Current status](docs/project-a/README.md)
- [Sanitized milestone history](docs/project-a/HISTORY.md)
- [Production roadmap](docs/project-a/ROADMAP.md)
- [Project A.1 expansion concept](docs/project-a/A1_CONCEPT.md)

The GitHub documentation intentionally excludes ROMs, ROM-derived assets, raw private diagnostic captures and private development-storage identifiers.

> **Important:** the documentation is ahead of the code currently committed on `main`. October 2026 Project A gameplay work has been developed and tested in a separate active working tree with guarded checkpoints/installers. Do not assume that cloning this repository currently reproduces Project A gameplay. Synchronizing the exact tested source/runtime baseline is a separate release-engineering milestone and must be done from the verified source snapshot, not reconstructed from documentation.
