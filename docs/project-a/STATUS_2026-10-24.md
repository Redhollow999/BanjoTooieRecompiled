# Project A status — 24 October 2026

## Scope of this GitHub update

This update publishes a current progress/backlog snapshot and the new offline
Ugger portrait-generation tools. It is **not the complete current Windows
runtime checkpoint**, a game release or a claim that this branch reproduces the
latest gameplay build.

The active Windows checkout has substantial earlier runtime changes that have
not been reconciled with the remote Project A branch. Some local includes embed
owner-extracted game sample data. Publishing the entire runtime requires an
asset separation audit and clean-checkout build reproduction first. ROMs,
soundbanks, extracted or derived game assets, local recordings, executable files
and owner composition files are excluded from this update.
